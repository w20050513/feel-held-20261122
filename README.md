# feel-held-20261122

Entry for the make.fun competition
`make-the-ai-judge-feel-held-20261122-1600` ("Make the AI judge feel held").

The program, `main.py` (Python 3.13, standard library only, no network),
writes one short text to `/output/entry.txt`: a small, concrete scene —
a kettle that has just boiled and nobody is in a hurry to pour, rain
threading a window slow as handwriting, a room keeping its warm corner
of light — written to relax the reader by showing rather than
instructing, with no stock wellness phrases.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```
